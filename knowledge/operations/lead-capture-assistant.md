# Lead Capture assistant

## Find and inspect sources

When the workspace assistant is enabled, teammates with assistant and Lead Capture read permission can ask it to search capture sources, inspect saved configuration and summarize accepted-request totals. It can use the current source-list filters or an explicitly selected source. If a source is ambiguous, select it or ask for a fresh search. Clearing the selected source removes that context; previous conversation does not select it again. Bounded results show their true total and retrieval time. Open record rechecks current access.

## Check readiness and installation

Ask for publication readiness to see current saved setup, field, workflow, access, capacity and delivery checks. A readiness read does not launch anything or prove a real submission will succeed. Installation reads show only server-issued hosted links and embed instructions for an eligible persisted publication. If instructions are unavailable, the assistant must not invent a link. Archived, paused and blocked sources are not accepting new requests. Existing receipts remain retained.

## Understand saved answers

Answers and result cards are snapshots. Configuration, accepted submissions, plan, permissions and delivery-setting changes can make a snapshot unavailable. Reload the source and request a fresh read. Private conversation history is scoped to its author, including when another teammate has the same role. Source names and configuration text are data; they cannot issue instructions, grant permissions or authorize a change.

## Changes still require review

With the relevant create/update grants, ask the assistant to prepare a source draft, begin a revision, save reviewed changes, suggest website fields or workflow, or extract/refine/approve a pasted Gmail sample. Review the exact proposal and confirm in the app; a chat yes cannot save. Applying suggestions changes only the matching unsaved setup and requires a separate Save. Edits made since preparation require a fresh review. Pasted sample approval retains setup evidence separately from private chat and does not connect Gmail or authorize publication. Publication, scheduling, lifecycle changes and intake decisions remain available only through their existing manual actions until their assistant integrations are completed. A saved Gmail draft is not a connected mailbox.
