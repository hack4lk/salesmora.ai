# Manage role permissions

## Find permissions

Open Settings and then its Permissions sub-page, also available as the indented Permissions item in the left menu. The general Settings page remains the default settings destination. Only the workspace Owner can change role permissions.

## Save changes

Review the role permission toggles and save changes. Changes are validated against eligible role ceilings and permission dependencies. A conflicting save must be reloaded before retrying. A saved future permission does not enable an unimplemented feature.

## Ownership safeguards

The workspace has one Owner. Ordinary role permission edits cannot create another Owner or remove the existing Owner. Admin is an operational role and cannot change role permissions. Membership and permissions are checked on the server for each protected operation.
