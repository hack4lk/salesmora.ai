# Workspace roles and access

## One role per teammate

Each workspace has one Owner, and each teammate has one permission role: Owner, Admin, Office or Field. The Owner can configure grants for eligible roles. Role labels alone do not grant unrestricted access; current saved permissions and implemented features determine access.

## Field access

Field teammates can work with assigned leads under the agreed role policy, but cannot create leads by default. Preparing and sending estimates are agreed future capabilities; their app features are not implemented yet. The current assistant must enforce the same restrictions as the app.

## Assistant permissions

The assistant cannot bypass your current app permissions. Hidden menu items, a previous conversation, a page name, or a request to act as Owner cannot grant access. It must check the selected workspace and current permissions before retrieving protected help or using data tools.
